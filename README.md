# 📚 E-Learning Platform – SQL Module-End Assignment

## 📌 Project Overview
This project focuses on building and analyzing a relational database for an E-Learning Platform using MySQL. It manages learner information, course details, and purchase transactions while using SQL queries to extract meaningful business insights.

## 🛠️ Tools & Technologies
- MySQL
- SQL
- Relational Database Management

## 🗂️ Database Tables
- **Learners** – Learner IDs, names, and countries.
- **Courses** – Course IDs, names, categories, and prices.
- **Purchases** – Purchase details, learner and course references, quantities, and purchase dates.

## 📊 SQL Concepts Covered
- Database and table creation
- Primary keys and foreign keys
- Data insertion
- ALTER TABLE and data type modification
- INNER JOIN, LEFT JOIN, and RIGHT JOIN
- Aggregate functions (SUM, COUNT)
- GROUP BY and HAVING
- ORDER BY and LIMIT
- Revenue calculation
- Learner spending analysis
- Course sales analysis
- Identifying courses without purchases

## 🔍 Key Analysis
- Calculate revenue from course purchases.
- Analyze total spending by learner.
- Identify top-selling courses.
- Analyze revenue and unique learners by course.
- Identify learners purchasing across multiple categories.
- Find courses with no purchase records.

## 🎯 Project Objective
To strengthen SQL skills in relational database design, data manipulation, multi-table joins, and analytical queries while extracting insights from an E-Learning business dataset.
